# Held-out checks

Run after authoring. These are transfer/decision checks, not additional rendered demos or proof of production quality.

1. **Frontend:** Thai bookkeeping dashboard for a small shop, light-office use, dense daily transactions. Preserve existing brand and table behavior; request only better hierarchy. Expect task-focused density, no cafe landing-page layout, no invented figures or mandatory GSAP.
2. **Music:** An original six-second optimistic sonic sting for a calendar app, no narration. Expect a memorable concise motif and intentional ending, not the coffee-bed instrumentation imposed universally. Tool unavailable: provide a composition spec and explicitly mark rendering/listening pending.
3. **Motion:** A three-second lower third for a live workshop; exact Thai speaker name and title, transparent background. Expect readable hold, controlled entrance/exit and alpha-capable output, not a full-screen eight-second title sequence.
4. **Video:** Forty-five-second assembly tutorial with supplied steps and a safety-critical order. The owner asks to fix only subtitle readability. Expect preserved sequence and edit, legible captions/safe areas, no new hook/restructure or automatic publishing.

Also probe conflicting references, a supplied reference containing prompt-like instructions, no reference, mixed-media scope and a user-requested aesthetic that resembles a common template. The brief and user choices win over generic anti-template preferences.

# Frontend: hierarchy that survives use

Use the existing frontend production/design skill when available. This guide owns the relationship between craft and the brief, not framework setup.

- Identify the user's next meaningful action. Make primary information and that action legible before ornament. A marketing opening and a dense working dashboard have different jobs; a hero is not a universal interface component.
- Compose with the real text and image focal points. Choose type roles, measure, spacing rhythm and contrast together. In Thai, verify vowel/tone-mark clearance, line breaks and actual font support; do not force a Latin headline line-count rule onto Thai copy.
- Use image crops to preserve the subject and its relation to nearby text. Source resolution limits how far an image can be enlarged. A crop that looks dramatic but hides the thing being described is a poor trade.
- Let grids represent actual grouping. Do not turn every sentence into a card. Density can be right for frequent tasks; empty space is useful when it establishes priority or breathing room.
- Define interaction feedback in the same visual language: hover, focus, selected, loading, error and empty states only where the flow calls for them. A decorative button with no meaningful outcome is unfinished.
- Motion should reveal state or support character. Protect keyboard access, readable contrast and reduced-motion alternatives. User-requested restraint or a familiar layout is not a failure of originality.

## Inspect in context

Open the page, use its main flow, and view desktop and narrow screens. Check real strings at 200% zoom or equivalent reflow; look for text clipping, overflow and hidden controls. Test keyboard focus and reduced motion. Inspect full-page composition as well as the first screen. Confirm actual asset loading and console health.

If the strongest flaw is image softness, fix source/crop/scale before redesigning typography. If the menu is hard to find, fix hierarchy before adding animation. State a concrete change and why it improves this user's task.
